Ecliptic longitudes of the planets

Ecliptic longitude is the angle along the plane of the Earth’s orbit, measured eastward from the March equinox of date, from 0° up to 360°. That zero point is 0° tropical Aries. The sign is the 30° sector the longitude falls in, and the degree is the remainder inside that sector.

The functions below are the ones in examples/positions.js. They take a UTC Date. Building that Date from a civil clock and an IANA zone is the overview. For the worked birth, 12 April 1994 at 07:42 in Asia/Singapore, the instant is 1994-04-11T23:42:00.000Z.

wrap(x)     = ((x mod 360) + 360) mod 360
sign index  = floor(wrap(L) / 30)     0 = Aries … 11 = Pisces
degree      = wrap(L) mod 30

The double modulo in wrap matters. In JavaScript, (-1) % 360 is -1, so a negative intermediate angle has to be shifted back into range before you divide by 30. The index then lines up with the table: 0 Aries, 1 Taurus, and so on through 11 Pisces.

Geocentric and tropical

Geocentric means the origin is the center of the Earth. The same instant gives the same geocentric longitude in Singapore and in New York. The city still enters the chart, because it supplies the time zone that turns the birth clock into that instant, and because the ascendant needs the city’s latitude and longitude.

Tropical means the zero of longitude is the equinox of the date you ask for, so precession is already in the number. astronomy-engine returns that equinox-of-date longitude. A sidereal longitude is the tropical longitude minus an ayanamsa. This page keeps the tropical value.

A chart’s sign uses the longitude and leaves the ecliptic latitude aside. Latitude is the angle north or south of the ecliptic plane. At the sample instant the Moon’s ecliptic latitude is about +1.92°, and Mars is about −1.07°. Either figure can be large enough to matter for an eclipse or an occultation. It does not move the sign.

Three library calls

The Sun, the Moon, and the planets come back through three functions. Each result is equinox-of-date ecliptic longitude, in degrees.

import { Body, Ecliptic, EclipticGeoMoon, GeoVector, SunPosition } from "astronomy-engine";

function wrap(deg) {
  return ((deg % 360) + 360) % 360;
}

function longitudeOf(body, date) {
  if (body === "sun") return wrap(SunPosition(date).elon);
  if (body === "moon") return wrap(EclipticGeoMoon(date).lon);
  return wrap(Ecliptic(GeoVector(body, date, true)).elon);
}

SunPosition(date).elon is the apparent geocentric ecliptic longitude of the Sun on the true ecliptic of date. Apparent here includes aberration.

EclipticGeoMoon(date) returns a spherical position. The longitude field is lon, the latitude field is lat, and dist is the geocentric distance in AU. The angles are on the true ecliptic of date: the equator is corrected for precession and nutation, and the ecliptic plane follows the slow change in obliquity. The theory behind the function is the Improved Lunar Ephemeris.

For Mercury through Pluto, GeoVector(body, date, true) is a vector from the center of the Earth in J2000 equatorial coordinates. Light-travel time is always removed, so the vector is where the body was when the light left it. The true argument applies aberration, which shifts the apparent direction by about 20″ of longitude. Ecliptic rotates that J2000 vector onto the true ecliptic of date. Read elon. The matching latitude is elat.

The body values are Body.Mercury, Body.Venus, Body.Mars, Body.Jupiter, Body.Saturn, Body.Uranus, Body.Neptune, and Body.Pluto. Pass the sample instant and print:

const when = new Date("1994-04-11T23:42:00Z");
longitudeOf("sun", when);     // 21.8477°
longitudeOf("moon", when);    // 32.4123°
longitudeOf(Body.Mars, when); // 357.8495°

Degrees and minutes

One degree is 60 arcminutes. Take the wrapped longitude, keep the remainder after multiples of 30, and convert that remainder to minutes by multiplying by 60. Round the minutes. If the rounded minute total reaches 60, carry a degree. If that carry produces 30°, the position is 0°00′ of the next sign.

const SIGNS = [
  "Aries", "Taurus", "Gemini", "Cancer", "Leo", "Virgo",
  "Libra", "Scorpio", "Sagittarius", "Capricorn", "Aquarius", "Pisces",
];

function formatLon(lon) {
  const n = wrap(lon);
  let sign = Math.floor(n / 30) % 12;
  let minutes = Math.round((n % 30) * 60);
  let deg = Math.floor(minutes / 60);
  minutes %= 60;
  if (deg === 30) {
    deg = 0;
    sign = (sign + 1) % 12;
  }
  return `${SIGNS[sign]} ${deg}°${String(minutes).padStart(2, "0")}′`;
}

The sample Sun is 21.847659°. Inside Aries that is 21° plus 0.847659 × 60 = 50.86′, which rounds to 51′. formatLon returns Aries 21°51′. Carrying through total minutes, rather than rounding the degree and the minute separately, is what makes 21.9917° print as 22°00′ of the same sign.

Daily motion and retrograde

A body is retrograde in longitude when the geocentric ecliptic longitude is decreasing. Sample the longitude one day later and fold the difference into the half-open range (−180°, +180°]. Negative means retrograde at that instant. Positive means direct.

function signedArc(fromDeg, toDeg) {
  return ((toDeg - fromDeg + 540) % 360) - 180;
}

function dailyMotion(body, date) {
  const later = new Date(date.getTime() + 24 * 60 * 60 * 1000);
  return signedArc(longitudeOf(body, date), longitudeOf(body, later));
}

Jupiter and Pluto are retrograde that day. The other eight are direct. For an outer planet the decrease is geocentric. Over the same day Jupiter’s heliocentric ecliptic longitude increased by 0.08°, and Pluto’s by 0.007°, while the Earth was passing them. A chart-level account of this condition is retrograde.

The Moon’s 11.79° is near the slow end of its range. Near perigee the Moon can cover about 15° in a day. An unknown birth clock therefore leaves the lunar degree uncertain by a large fraction of a sign, which is why that placement wants a known time. The Moon is the reader-facing treatment of the same placement.

What these longitudes leave out

The numbers above are geocentric. The Moon’s horizontal parallax reaches about 1°, so a topocentric Moon, seen from a point on the surface, can differ by a fraction of a degree up to about that amount. Aberration is already included for the Sun, through SunPosition, and for the planets, through GeoVector(..., true). It is about 20″ of longitude. For a chart printed to the nearest minute of arc, keep the aberration correction and treat topocentric parallax as a later refinement. The Moon is the body that refinement moves.

Those ten longitudes are the positions a wheel plots around the ecliptic. The chart at astralhoro.com/chart is that wheel for a birth you type in. The ascendant is a different angle: it is a direction on the horizon, computed on the next page.
