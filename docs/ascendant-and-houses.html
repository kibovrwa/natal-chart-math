The ascendant, the midheaven, and houses

The ascendant is the ecliptic longitude on the eastern horizon. The midheaven is the ecliptic longitude on the local meridian, on the half above the horizon. Both depend on the instant and on the geographic place. Once the instant is fixed, the planet longitudes do not.

The sign of the ascendant is the rising sign. In the worked example, 12 April 1994, 07:42, Singapore, that sign is Taurus, at 1°44′. Rising describes that angle the way a chart reader meets it. The formulas here are the ones in examples/ascendant.js.

The sample instant, after the zone conversion on the overview, is 1994-04-11T23:42:00.000Z. Latitude φ is 1.3521° north. Longitude λ is 103.8198° east.

Sidereal time

SiderealTime(date) returns Greenwich apparent sidereal time in hours, in the half-open range [0, 24). Apparent sidereal time includes the equation of the equinoxes, so the zero point is the true equinox of date. When the value is 0, the Greenwich meridian is aligned with that equinox.

Geographic longitude is east-positive, in degrees, so a place west of Greenwich is negative. Dividing by 15 converts degrees to hours: the Earth turns 15° of longitude in one sidereal hour.

LST  = GAST + λ / 15
RAMC = wrap24(LST) × 15

wrap24(h) = ((h mod 24) + 24) mod 24

wrap24 folds the hours into [0, 24) before the multiplication. RAMC, the right ascension of the local meridian, is that hour angle written in degrees. It is the right ascension culminating at the place. The midheaven is the same direction, expressed as ecliptic longitude.

import { SiderealTime } from "astronomy-engine";

function wrap(deg) {
  return ((deg % 360) + 360) % 360;
}

function ramcDegrees(date, lonDeg) {
  const lstHours = SiderealTime(date) + lonDeg / 15;
  return wrap((((lstHours % 24) + 24) % 24) * 15);
}

At the sample instant, Greenwich apparent sidereal time is 13.0304 hours. Adding 103.8198 / 15 hours of east longitude and converting to degrees gives RAMC 299.28°. East of Greenwich, local sidereal time is ahead of Greenwich. The opposite sign of longitude shifts sidereal time by 2|λ| / 15 hours and moves the ascendant by a large angle. New York is about −74°. Singapore is about +104°.

Obliquity

The horizon formulas need the true obliquity of date, ε. That is the tilt between the ecliptic and the equator, including nutation. In astronomy-engine it is e_tilt(MakeTime(date)).tobl, in degrees. e_tilt takes an AstroTime, which MakeTime builds from a Date. For the sample, ε is 23.4387°. The mean obliquity, without nutation, is the sibling field mobl. Use tobl for the ascendant and the midheaven.

Ascendant and midheaven

With RAMC, latitude φ, and ε converted to radians:

MC  = atan2( sin RAMC,  cos RAMC · cos ε )
ASC = atan2( cos RAMC,  −(sin RAMC · cos ε + tan φ · sin ε) )

Math.atan2(y, x) reads the quadrant from the signs of both arguments and returns radians. Convert to degrees and wrap into [0°, 360°). Pass radians into Math.sin, Math.cos, and Math.tan. RAMC from the sidereal-time formula is still in degrees when it comes back, so convert it first. Swapping the two arguments of atan2 sends the angle to the wrong quadrant.

Latitude is north-positive. The factor tan φ carries the hemisphere, and the same expression is used north and south of the equator. At φ = ±90°, tan φ is undefined. Keep the latitude strictly inside the poles.

import { e_tilt, MakeTime, SiderealTime } from "astronomy-engine";

const rad = (d) => (d * Math.PI) / 180;
const deg = (r) => (r * 180) / Math.PI;
const wrap = (d) => ((d % 360) + 360) % 360;

function ramcDegrees(date, lonDeg) {
  const lstHours = SiderealTime(date) + lonDeg / 15;
  return wrap((((lstHours % 24) + 24) % 24) * 15);
}

function midheaven(ramcDeg, epsDeg) {
  const ramc = rad(ramcDeg);
  const eps = rad(epsDeg);
  return wrap(deg(Math.atan2(
    Math.sin(ramc),
    Math.cos(ramc) * Math.cos(eps)
  )));
}

function ascendant(ramcDeg, latDeg, epsDeg) {
  const ramc = rad(ramcDeg);
  const lat = rad(latDeg);
  const eps = rad(epsDeg);
  const y = Math.cos(ramc);
  const x = -(Math.sin(ramc) * Math.cos(eps) + Math.tan(lat) * Math.sin(eps));
  return wrap(deg(Math.atan2(y, x)));
}

const when = new Date("1994-04-11T23:42:00Z");
const eps = e_tilt(MakeTime(when)).tobl;
const ramc = ramcDegrees(when, 103.8198);
const asc = ascendant(ramc, 1.3521, eps);
const mc = midheaven(ramc, eps);

This horizon is geometric. Atmospheric refraction lifts the apparent horizon by about 34′ of altitude, which nudges the ascendant by a fraction of a degree. The formula also ignores the observer’s height above the sea.

An error of about two hours can change the rising sign. That two hours is the mean across the twelve signs. Away from the equator, consecutive signs take unequal times to rise. At Singapore’s latitude of 1.4° the inequality is small. House cusps want a known clock.

Whole-sign houses

House 1 is the sign that contains the ascendant. The next sign, in order of increasing longitude, is house 2, and so on around the zodiac. Every degree of the rising sign is house 1, including the degrees of that sign that rose earlier in the hour.

house(L) = ((floor(wrap(L) / 30) − floor(wrap(ASC) / 30) + 12) mod 12) + 1

The twelve cusps are the starts of those signs. The first cusp is floor(wrap(ASC) / 30) × 30, and each later cusp adds 30°.

function wholeSignCusps(asc) {
  const start = Math.floor(wrap(asc) / 30) * 30;
  return Array.from({ length: 12 }, (_, i) => wrap(start + i * 30));
}

function wholeSignHouse(lon, asc) {
  const sign = (value) => Math.floor(wrap(value) / 30) % 12;
  return ((sign(lon) - sign(asc) + 12) % 12) + 1;
}

The Singapore ascendant is 31.73°, so floor(31.73 / 30) × 30 is 30°. House 1 begins at 0° Taurus. The cusps are 0° of Taurus, Gemini, Cancer, Leo, Virgo, Libra, Scorpio, Sagittarius, Capricorn, Aquarius, Pisces, and Aries.

The midheaven at 297.22° is Capricorn. The sign index is floor(297.22 / 30) = 9, the ascendant’s sign index is 1, and (9 − 1 + 12) mod 12 + 1 is 9. The midheaven is whole-sign house 9. The 10th cusp is 0° Aquarius.

Equal houses

Equal houses use the same 30° steps, measured from the ascendant degree itself. House 1 is the 30° of longitude that begins at the ascendant and runs in the direction of increasing longitude. Cusp k, counting from 0, is wrap(ASC + 30° · k). The descendant falls on cusp 7, because that cusp is the ascendant plus 180°. The midheaven falls on a cusp only when its longitude happens to land there.

house(L) = floor(wrap(L − ASC) / 30) + 1
function equalCusps(asc) {
  return Array.from({ length: 12 }, (_, i) => wrap(asc + i * 30));
}

function equalHouse(lon, asc) {
  return Math.floor(wrap(lon - asc) / 30) + 1;
}

From the printed ascendant 31.73°, every equal cusp sits at 1°44′ of its sign. The 10th equal cusp is 301.73°, Aquarius 1°44′. The midheaven at 297.22° gives wrap(297.22 − 31.73) = 265.49, and floor(265.49 / 30) + 1 is 9. Under both systems in this chart, the midheaven is a house 9 angle, and the 10th cusp is a different longitude.

High latitude

Whole-sign and equal houses need a finite ascendant, and they stay defined as the geographic latitude approaches the poles, for as long as tan φ itself is finite. Placidus needs a rising and setting point. examples/houses.js leaves Placidus unset when the absolute latitude is greater than 66°, which is where part of the ecliptic stays above the horizon or stays below it.

The same UTC instant at Tromsø, 69.6492°N, 18.9553°E, has the ascendant at 236.12°, Scorpio 26°07′, and the midheaven at 216.75°, Scorpio 6°45′. The two angles share a sign, so the whole-sign house of the midheaven is 1. The midheaven is 19.38° of longitude before the ascendant, so the equal house of the midheaven is 12. In both systems the cusps stay 30° apart.

The longitude and the house number

Compute the longitude, compute the ascendant, then call wholeSignHouse or equalHouse. The longitude is the astronomy. The house number is the system you chose. A wheel that shows the angles together with one house system is what astralhoro.com/chart draws. How to read a birth chart is about reading those house numbers once the cusps exist.
